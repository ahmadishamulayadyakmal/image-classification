# Image Classification

Repository eksperimen untuk klasifikasi gambar kucing dan anjing.

> Status: repository ini saat ini masih berupa kerangka awal dan belum berisi implementasi model.

## Tujuan

Proyek ini ditujukan untuk membangun dan mengevaluasi model klasifikasi citra yang membedakan dua kelas:

- Cat
- Dog

## Alur Pengembangan

Saat implementasi ditambahkan, repository dapat mengikuti alur berikut:

1. Menyiapkan dan memvalidasi dataset.
2. Melakukan preprocessing serta augmentasi gambar.
3. Melatih model klasifikasi.
4. Mengevaluasi performa pada data pengujian.
5. Menyimpan model dan hasil eksperimen.
